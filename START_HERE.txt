IF SOMETHING GOES WRONG
═══════════════════════════════════════════════════════════════════════════════

❌ "Git is not recognized"
  → Install Git: https://git-scm.com/download/win
  → Restart PowerShell

❌ "Authentication failed"
  → Using GitHub PASSWORD instead of ACCESS TOKEN
  → Use the TOKEN you copied in Step 2 (not your password)

❌ "GitHub Actions workflow failed"
  → Check logs: https://github.com/YOUR_USERNAME/vinerox/actions
  → Click failed run → Click "build" job for details
  → 99% of time: Just timeout, re-run workflow by clicking "Re-run jobs"

❌ "Google Play still rejects AAB"
  → Verify: build.gradle.kts has compileSdk = 35 AND targetSdk = 35
  → Check Google Play error message for specific requirement
  → Rebuild and re-upload if needed
